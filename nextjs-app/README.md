# Pietra Next.js App (Entorno de Prueba)

Proyecto paralelo en Next.js 15 + TypeScript para migración progresiva del sitio de Marmolería Pietra.

## Ejecutar localmente

```bash
npm install
npm run dev
```

## Build de producción

```bash
npm run build
npm run start
```

## Deploy de prueba en Vercel

1. Importar el repositorio en Vercel.
2. Seleccionar `nextjs-app` como **Root Directory**.
3. Mantener el framework detectado como `Next.js`.
4. Crear un entorno preview (no apuntar dominio de producción).
